# Pokedex

A small Pokedex web app built with HTML, CSS and JavaScript.
It loads Pokemon data from the [PokeAPI](https://pokeapi.co/).

## Features

- List of Pokemon cards with image, name and types
- Card colors based on the Pokemon type
- "Load more" button with loading screen
- Detail dialog with stats and navigation between Pokemon
- Search by name (at least 3 letters)
- Responsive layout (down to 320px)

## Tech

- HTML, CSS, JavaScript (fetch API, async/await)

## Run locally

Open `index.html` with a local server (for example the VS Code extension "Live Server").
